# Продуктмейстер

Небольшой проект, реализующий классы, связанные с кулинарными рецептами и продуктами.

## Установка

Чтобы развернуть проект локально, выполните следующие команды в терминале:

1. Склонируйте репозиторий:
   ```bash
   git clone <ссылка_на_репозиторий>


1.	Перейдите в папку проекта:
cd <имя_папки_репозитория>

	2.	Установите необходимые зависимости:
pip install -r requirements.txt

Использование
Вся основная часть кода (классы Ingredient, Recipe, DietaryRecipe, ShoppingList) находится в файле recipes.py.
Для запуска тестов (проверки корректности работы кода) используйте команду:
pytest
